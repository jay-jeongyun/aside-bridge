# Repository metadata (for GitHub)

## Description (max 350 chars)

Let a sandboxed AI agent (e.g. the Aside browser agent) control native macOS apps: AppleScript,
JXA, shell, guarded keyboard/mouse input, screenshots and OCR, run outside the sandbox through a
local, token-protected helper. Unofficial, not affiliated with Aside.
